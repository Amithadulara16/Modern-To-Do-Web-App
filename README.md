

# 📌 **GitHub Project Description**

## 📝 Smart To-Do Web Application

A modern and user-friendly To-Do List web application built using React and JavaScript. This application allows users to manage their daily tasks efficiently with a clean interface and essential CRUD operations.

---

## 🚀 Features

* 🔐 **Login System**

  * Simple authentication (static username & password)
  * Secure access to dashboard

* 📊 **Dashboard**

  * Clean and responsive UI
  * Displays all tasks in a structured format

* 📝 **Task Management**

  * ➕ Add (Insert) new tasks
  * ✏️ Update (Edit) existing tasks
  * ❌ Delete tasks
  * ✅ Mark tasks as completed

* 💾 **Local Storage**

  * Saves tasks in browser
  * Data persists after refresh

---

## 🛠️ Technologies Used

* Frontend: React
* Language: JavaScript
* Styling: CSS
* Build Tool: Vite
